# 리포트 평가 체크리스트 (축별)

리포트 하나에 등급 하나를 매기지 않는다. 축마다 따로 1~3점 + 근거 문장(원문 그대로, 쪽)을 단다. 해당 없는 축은 "해당 없음".
총점은 없다. 쓰임: 챗봇이 피드백할 때 그 축에서 잘한 선배 리포트를 골라 보여준다 (NOTES 14절).
세대(학기) 구분 없이 같은 기준. 하계·동계 리포트도 일괄로 깎지 않는다.

| 점수 | 뜻 |
|---|---|
| 3 | 이 축의 참고 사례로 보여줄 만하다 |
| 2 | 기본은 했다 |
| 1 | 이 축이 비었거나 겉핥기 |

## 1. 투자포인트 (리포트 안에서 확인되는 것만. 당시 컨센서스는 찾지 않는다)
- 시장 인식과 다른 점을 리포트가 직접 밝혔나 ("시장은 ~로 보지만 ~"). 밝혔으면 그 주장에 근거가 있나.
- 포인트끼리 겹치지 않나 (예: "수출 성장"과 "미국 성장"은 겹친다).
- 각 포인트가 추정 가정 → 목표주가까지 따라가지나 (예: "CAPA 증설"이 매출 추정의 Q로 들어갔나).

## 2. 탑다운
- 산업 → 경쟁 구도 → 이 회사로 범위가 한 단계씩 좁혀지나. 산업 이야기가 회사 결론과 따로 놀지 않나.
- 산업분석이 기업을 고르는 "조건"을 내놓고, 회사가 그 조건에 맞는다는 걸 숫자로 보이나.

## 3. 리서치 깊이
- 남들이 안 쓴 데이터를 직접 찾고 가공했나 (수출 통계, 검색량, 채널 조사, 회사 자료를 쪼갠 계산).
- 공시·뉴스 요약 수준이면 1점.

## 4. 추정
- Q×P(×C) 구조가 있고 가정마다 근거가 있나.
- 과거 실적과 맞춰 봤나. 본문 숫자와 엑셀 모델 숫자가 맞나.

## 5. 밸류에이션
- 방법을 고른 이유가 있나. Peer가 적절한가. 배수·g·WACC 가정의 근거가 있나.
- 계산 실수는 없나 (검산한다. 예: 한국타이어 모델의 회사채 금리 덧셈).

## 6. Peer 비교·케이스 스터디
- 비교에서 "그래서 이 회사는"이라는 결론이 나오나.
- Peer 표만 있고 결론이 없는 겉핥기 비교는 1점.

## 7. 글 (기준 글: TORM·삼양식품. 문장 리듬은 TORM, 제목 카피는 삼양식품. 둘이 같이 지키는 것이 기준선)
구성과 짓기를 나눠 본다. 구성은 무엇을 어떤 순서로 말하나, 짓기는 같은 내용을 문장으로 어떻게 빚나.

| 항목 | 볼 것 | 재는 법 |
|---|---|---|
| ① 날카로움 | 판단에 "얼마나?"가 붙어 있나 (숫자, 비교 기준) | 스크립트: 판단 문장 중 숫자 비율 (연도 제외) |
| ② 압축 | 없어도 되는 말이 없나, 한 문장에 꾹꾹 눌러 담았나 | 스크립트: 평균 문장 길이, 군더더기 밀도, 정보 밀도 |
| ③ 문단 구성 | 첫 문장이 그 문단의 결론인가(첫 문장만 이어 읽으면 요약) / 문단 하나에 주장 하나 / 판단 하나에 근거 여럿 / 숫자나 판단으로 끝내나 / 예고한 개수만큼 받나 / 반론을 문단 안에서 받나 | 읽고 판단 |
| ④ 문장 짓기 | 근거 → 결론을 "고려하면·감안하면"으로 잇나 / "통해·바탕으로" 같은 군더더기가 적나 / "기대된다·보인다"로 끝을 흐리지 않나 / 숫자를 짧게 접나 ("WTI $105·브렌트유 $126", "$3.00→$4.30") | 스크립트 + 읽고 판단 |
| ⑤ 어휘 | 업계 서술어(견조, 견인, 수혜, 유효, 제한적, 기우, 아직 이르다) / 구어체가 없나 / 서술어가 정확한가(판단에 "예정", 좋은 일에 "탓" X) / 같은 수식어 반복("단순", "작용") / 표기·지칭 통일(Capa/CAPA, 동사/회사명) / 공식 표현("A가 아닌 B", "복합적으로 작용") / AI 상투어 | 스크립트 + 어휘사전 |
| ⑥ 제목 카피 | 소제목이 주장을 담나(제목만 이어 읽어도 논리가 보이나) / 첫 문장이 소제목을 받나 / 말장난이어도 주장이 들어 있나("CAPA 이상 무" O, "짐은 나한테 다 맡겨" X) | 읽고 판단 |

스크립트 값은 `tools/rag/style_metrics.py` → 비공개 저장소 `eval/style_metrics.jsonl`. 리포트 414개의 분위수와 기준 글 값은 `eval/style_metrics_summary.json`.
스크립트 값은 순위를 보는 용도다. 한 리포트의 점수는 읽고 정한다.
