## 리본 헬퍼 (4막에서 도입)

## 만들 때 반드시 지키는 규칙 (사용자가 매번 지적하지 않아도 되게)

1. **누르지 않은 버튼의 결과물은 화면에 없다.** 다음 막 미리보기 금지. 요소의 초기 상태를 `opacity: 0` 으로 두고, 해당 `press()` 직후에만 나타나게 한다.
2. **버튼 누름은 확실히 보인다.** 짙은 파랑(`rgba(27,63,122,1)`) 채움 + 밝은 링(`.ring`)이 퍼짐 + 눌렸다 튕기는 스케일. `hold` 초만큼 눌린 상태 유지. **글자색은 건드리지 않는다** — 전환 중간에 대비가 무너져 `check` 가 걸린다.
3. **PRESS 와 reveal 은 0.1~0.5초 안에 붙는다.**
3-c. **5막부터는 리본 그룹을 돋보기로 뽑아온다.** `zoomGroup("그룹명", tIn, tOut)` — **종이 왼쪽 아래(140, 768)에 1.55배**로 세운다 — 화면을 왼쪽=설명+도구 / 오른쪽=문서로 가른다. 복제본이 GSAP 인라인 상태를 물려받으므로 `transform/opacity` 를 씻어내야 한다. `press()` 는 돋보기가 있으면 자동으로 그쪽을 누른다.
3-b. **버튼에서 결과물까지 연결선을 긋는다.** `chrome.html` 의 `CONN` 배열에 `{t, btn, ex, ey, out}` 한 줄 추가하면 끝.
   - 선은 리본 층(z-index 3)에 그려져 페이지 위에 올라간다.
   - 끝점 `ex, ey` 는 **페이지의 CSS 좌표 + (600, 520)**. 예: `#h1` 이 `left:205.8 top:96` → 전역 `(805.8, 616)`, 왼쪽 14px 띄워 `ex:792`.
   - `pathLength="1"` 로 길이를 정규화해 뒀으므로 글꼴 로딩 후 경로가 바뀌어도 애니메이션이 유효하다.
   - 선이 다 그려진 뒤 **최소 0.6초는 머문 다음** 사라지게 할 것. 카메라 이동은 그 뒤에.
4. 새 막을 붙인 뒤 **반드시 이 순서로** 확인한다:
   ```
   python tools/check-order.py      # 전역 타임라인 — 순서 사고 잡기
   npm run check                    # 에러 0 확인 (대비·레이아웃 포함)
   npx hyperframes snapshot --at <각 press 직후>   # 눈으로 확인
   npm run render
   ```
5. 대비(contrast) 에러가 나면 **어둡게 하지 말고 밝게** 풀거나, 전경/배경을 동시에 크로스페이드하지 않는다.

## 구조 규칙 (3막에서 확정)

- **리본은 항상 페이지 위** — `#sceneChrome { z-index: 3 }`, 문서는 `clip-path: inset(404px 0 0 0)` 로 리본 아래에서만 보인다. 워드와 동일.
- **막 = 타임라인 구간**. `cover.html` 한 장을 계속 쓰고 막마다 카메라(`#pagesWrap` transform)만 옮긴다. 3막 close-up 값: `scale 1.35, x -546, y -357` (남색 박스~Stock Price 가 한 화면).
- **리본 집중 표시**: 다른 그룹을 어둡게 하지 않는다(대비 무너짐). 해당 그룹만 배경 `#2a4677` + 상단 3px `#8faadc` 바 + 그룹 라벨을 크림으로. 버튼은 `[data-btn="주가 차트"]` 로 짚어 배경 플래시 + 살짝 눌림.
- **자동으로 채워지는 값은 `.av` 클래스**로 두고 처음엔 `opacity:0`. 해당 막에서 파랑(`#2f5597`)으로 채운다.

## 레이아웃 규칙 (겹침 사고 방지)

화면을 세 구역으로 고정한다. **구역을 넘나들면 반드시 겹친다.**

| 구역 | x 범위 | 내용 |
|---|---|---|
| 리본 | 24 ~ 1896 (y 206~402) | 항상 맨 위, z-index 3. 좌우 여백 24px — 없으면 첫 그룹이 잘린다 |
| 왼쪽 | 140 ~ 580 | 자막(y 552~730) + 돋보기 패널(y 768~970) |
| 오른쪽 | 600 ~ 1520 | 문서 |

- 카메라 `CAM_A4 = scale 1.2 / x +40 / y -26` → 페이지 640~1504. 왼쪽 구역과 60px 떨어진다.
- 연결선은 **왼쪽 패널에서 오른쪽 문서로** 들어간다(`side` 생략). 리본 높이를 유지하다 목표 근처에서 내려오는 곡선이라 자막 위를 지나지 않는다.
- 자료 번호·장 번호는 **실물대로 검정**. 붙는 순간에만 파랑이었다가 0.8초에 걸쳐 검정으로 가라앉는다.
- `.area` 는 반드시 `position: relative` — 아니면 안의 표가 캡션을 덮고 2칸을 가로지른다.
