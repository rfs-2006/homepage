# 홈페이지 운영 인수인계

caurfs.kr를 돌리는 데 쓰는 서비스와, 개인 계정에서 **학회 공용 계정**으로 옮기는 방법이에요.
키·비밀번호·인증서는 이 문서에 쓰지 않아요. 비밀번호 관리자(학회 공용 금고)에만 둬요.

진행 상황은 운영 대시보드(AGORA → 운영 → "유지비 · 계정" 표)의 **관리 계정**·**이전** 칸에 적어요.

## 0. 먼저 준비할 것

1. **학회 공용 이메일 하나**: 실제로 메일을 받을 수 있어야 해요. 모든 서비스를 이 주소로 묶어요.
2. **비밀번호 관리자**(예: Bitwarden 조직): 서비스별 아이디·비밀번호, 2단계 인증 복구 코드, 서버 접속 방법을 넣어요. 회장이 바뀌면 이 금고만 넘겨요.
3. **결제 카드**: 학회 카드 하나로 통일해요. 서비스마다 결제 수단을 이 카드로 바꿔요.

## 2. Supabase Secrets 이름 (값은 금고에)

| 이름 | 쓰는 함수 | 내용 |
|---|---|---|
| `MEMBER_ADMINS` | member-admin | 운영 대시보드·가입 승인을 쓸 수 있는 로그인 이메일 (쉼표로 여러 개) |
| `ADMIN_PHONE` | member-signup | 가입 신청 알림 문자를 받을 번호 |
| `SOLAPI_API_KEY` · `SOLAPI_API_SECRET` · `SOLAPI_SENDER` | member-signup, member-admin, agora-sms | 솔라피 키와 발신번호 |
| `RESEND_API_KEY` · `MAIL_FROM` | member-signup, member-admin, agora-sms | 알림 메일 (받는 주소는 대시보드에서 바꿈) |
| `GA_PROPERTY_ID` · `GA_SA_KEY` | member-admin | GA 속성 ID, 서비스 계정 키 JSON |
| `CARD_SECRET` | member-verify, member-admin | 학회원증 QR 서명 키 (긴 무작위 문자열). 바꾸면 이미 찍은 카드 QR이 전부 무효가 돼요 |
| `LEDGER_ADMINS` (선택) | member-admin | 회계장부·증빙을 볼 수 있는 로그인 이메일 (쉼표로 여러 개). 없으면 `MEMBER_ADMINS` 전체 |

### Supabase 함수·테이블

| 함수 (`supabase/functions/`) | 하는 일 | 로그인 |
|---|---|---|
| member-signup | 회원가입 신청 | 없음 |
| member-admin | 가입 승인·운영 대시보드·학회원증 발급(card_list·card_save·card_revoke)·회계장부(ledger_*·receipt_*) | 관리자(`MEMBER_ADMINS`), 회계장부는 `LEDGER_ADMINS`가 있으면 그 사람만 |
| member-verify | 학회원증 QR 확인 (`/v/` 화면이 사이트 공개 키로 부름) | 없음 |
| agora-sms | AGORA 선배님 연락처 문자 | 학회원 |
| wk-image | 위클리 글쓰기의 노션 사진 가져오기 | 운용팀 계정 |

테이블 SQL(`supabase/sql/`, SQL Editor에서 한 번 실행): `ops_state.sql`(대시보드·회계장부), `ledger_log.sql`(회계장부 접근 기록 + 비공개 Storage 버킷 `ledger`), `agora_sms_log.sql`·`agora_member_only.sql`(AGORA), `member_cards.sql`(학회원증), `shared_checks.sql`(공유 체크리스트 /check/).

Storage 버킷: `ledger` (**비공개**, 증빙 파일. 5MB, pdf·jpg·png·webp). `ledger_log.sql`이 만들어 주고, Public으로 바꾸지 않는다.

### 회계장부

- 장부는 `ops_state` 테이블의 key `ledger`(줄 목록), 접근 기록은 `ledger_log`(최근 500건), 증빙 파일은 비공개 버킷 `ledger`. 셋 다 RLS·정책 없음이라 사이트에서는 못 읽고 member-admin 함수만 읽고 쓴다. 공개 저장소에는 장부·엑셀을 올리지 않는다.
- 보는 사람: `LEDGER_ADMINS`의 이메일(없으면 `MEMBER_ADMINS`). 열람·저장·내려받기·증빙 올림/열람이 전부 누가·언제로 남고, 대시보드 → 회계장부 → 접근 기록에서 최근 50건을 본다.
- 올리는 법: 대시보드 → 회계장부 → 열기 → 엑셀 올리기(.xlsx, ‘날짜’·‘항목’ 머리줄이 있는 시트, 날짜는 `26.08.05` 꼴, 지출은 음수여도 됨) → 새 줄·바뀐 줄·빠진 줄과 계(잔액) 불일치를 확인하고 저장. 저장하면 장부 전체가 그 엑셀로 바뀐다(증빙은 같은 날짜·항목 줄에 그대로 붙어 있음).
- 금액은 가려져 있고 ‘금액 보기’는 60초 뒤 다시 가려진다. 10분 동안 손대지 않으면 잠기고, 장부는 브라우저 저장소에 남지 않는다. 증빙은 줄마다 ‘첨부’, 볼 때는 60초짜리 주소로 새 탭.

### 학회원증

- 실물 카드의 QR은 `https://caurfs.kr/v/#<카드번호>.<서명>`. `#` 뒤는 서버로 가지 않고, `/v/` 화면이 member-verify에 보내 확인해요.
- 발급·수정·정지·QR(PNG)은 운영 대시보드 → 학회원증. 카드를 잃어버리거나 탈퇴하면 **정지**를 누르면 같은 QR이 바로 "효력이 정지된 카드"로 나와요. 기간이 지나도 같아요.
- 확인 화면은 초 단위 시계·움직이는 무늬·30초마다 재조회로 캡처와 구별돼요. 화면 속 주소가 caurfs.kr인지 같이 보면 돼요.
- `CARD_SECRET`은 처음 한 번만 정해요. 바꾸면 카드를 전부 다시 찍어야 해요.

## 3. Polaris 서버

- 접속: `ssh root@211.233.206.66` (접속 방법·키는 금고)
- 코드 갱신: `polaris-update main` → `systemctl restart polaris`
- 설정: `/etc/polaris.env` (`RAG_ANTHROPIC_API_KEY`, `VOYAGE_API_KEY`, `OPS_ADMINS`, `WK_WRITERS` 등. 항목 설명은 `tools/rag/server.py` 맨 위)
- 사용량 기록: `~/polaris-usage.json` (대시보드의 Voyage·질문 수)
- 서버를 새로 만들 때: 비공개 저장소 `rfs-cafe-data`를 받고, 위 설정 파일을 옮긴 뒤, api.caurfs.kr의 DNS(Netlify)를 새 서버 주소로 바꿔요.

## 4. 옮기는 순서

1. 학회 공용 이메일과 비밀번호 금고를 만든다.
2. 초대만 하면 되는 곳부터 옮긴다: Netlify, Supabase, GitHub, GA·서치콘솔, Anthropic.
3. 새로 가입해서 키를 바꾸는 곳: Voyage, Resend, Google Cloud.
4. 서류가 필요한 곳: 솔라피 발신번호, 도메인 명의.
5. 서버는 무료 크레딧이 끝날 때 학회 계정으로 새로 만든다.
6. 다 옮기면 **키를 전부 새로 발급**하고 옛 키를 지운다. 그다음 개인 계정을 각 서비스에서 뺀다.
7. 대시보드 "유지비 · 계정" 표의 이전 칸을 "학회 계정"으로 바꾼다.
